About

Builder who owns the pipeline

I’m a Computer Engineering student at UC Davis (Mathematics minor) who ships software end-to-end. At ASUCD Innovation & Research Lab I develop production systems for Aggies on the Move — unifying mobility feeds from 9+ campus partners into PostgreSQL warehouses and React dashboards used daily by researchers and staff.

I also ship AI products: Tone monitors deployed LLMs for behavioral drift (embedding-space MMD, token KL, persona cosine), and Omnitrix is an always-on desktop assistant — screen-aware context, local Ollama reasoning, and vector memory — engineered for privacy and speed.

Looking for teams that care about impact: internships, research labs, and ambitious product builds in full-stack, data platforms, LLM systems, and computer vision.

Tone

Behavioral drift detector for LLM outputs

Live Aug 2026 – Present

Deployed LLMs don’t fail loudly — they drift. Tone treats tone, factual, and persona shifts as an observability problem with continuous probes and a weighted drift score.

  • Sampler + embedder (all-MiniLM-L6-v2) + ChromaDB; detector combines MMD, token KL, and cosine
  • React + Recharts dashboard with heatmap, alerts, JWT/Google auth, encrypted API keys
