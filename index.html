Tone

LLM reliability stack — prevent, detect, diagnose drift

Live Aug 2026 – Present

Deployed LLMs don’t fail loudly — they drift. Tone is a three-layer reliability stack: catch behavioral regressions before merge, monitor production, and diagnose a single chat when it goes off-goal.

  • Runtime monitor — scheduled tone / fact / persona probes, MiniLM + ChromaDB, MMD / KL / cosine heatmap alerts, and background jobs so long sample runs don’t die on proxy timeouts
  • Chat review — paste a transcript or upload a ChatGPT export; per-turn goal-drift timeline, peak/first-alert, and steering tips from the connected LLM or Tone heuristics
  • llmtest — “pytest for AI behavior”: semantic equals / tone / excludes assertions, snapshot baselines, and a GitHub Action that fails PRs on drift
  • Generate llmtest — from a drifted chat, emit distinct probes with real-reply baselines (style personas + adversarial excludes), then copy-paste into CI — production signal → prevention
  • FastAPI + React; JWT / Google auth; encrypted API keys; OpenAI-compatible connectors; live at tonehq.xyz / api.tonehq.xyz

Review AI Detector

Chrome extension + ML API for review trust on 13 sites

Live · Chrome Web Store Aug 2026 – Present

Shoppers can’t tell if reviews are human or AI-generated. Built a niche detector for short, informal product reviews — with a high-precision threshold so real customers aren’t falsely flagged.

  • Manifest V3 extension — per-site adapters (Amazon, Yelp, Booking, Trustpilot, +9 more); listing trust card, per-review badges, hover signals
  • FastAPI on Render — calibrated sklearn hybrid + listing analysis: template clusters, posting bursts, adjusted ratings, visit history sparklines
  • Trained on matched human/AI review pairs; evasion-tested (paraphrase, typos, splice); false-positive rate prioritized over raw accuracy
  • Production API at ai-comment-checker.onrender.com; live on the Chrome Web Store
