Harvest Vault

Roblox farming simulator — grow crops, hatch pets, unlock a private estate.

Harvest Vault is a full-loop Roblox farm game with server-authoritative planting and harvest, pet followers, rebirth progression, world shops, and a private estate zone players unlock and expand. Built in Luau with DataStores, remotes, and a cohesive client UI — published and playable on Roblox.

Core loop

Select a seed → plant on soil pads → wait through weather-aware growth → harvest for coins → buy better seeds, land, gear, and pets → rebirth for permanent multipliers. The loop is tuned so early sessions teach planting quickly while late game opens estate scale and automation.

Systems

  • Farming — server-validated plant / harvest, mutations, vault-at-risk coins, free seed ladder by rebirth.
  • Shops — world stalls (seeds, land, pets, gear, decor) plus a phone shop for body / auto / Robux packs.
  • Pets — egg hatchery, inventory vs follow caps, sell / grow / mutation bonuses while following.
  • Gear — sprinklers, fertilizer, growth lamps with tiered unlocks and farm prop visuals.
  • Automation — auto farmer, planter, and seed buyer with a seed picker UI.
  • Meta — daily rewards, leaderboards, settings (mute music/SFX, hide emotes), SFX + sell feedback.

Private estate

After filling hub land, players unlock a private estate zone: up to 64 fields, personal shop stalls, decor per field, and same-server visits so friends can browse each other’s markets. Hub and estate plots relocate cleanly through PlotService / EstateService.

Architecture

  • Server modules — CropService, ShopService, PlotService, EstateService, PetService, DataManager, and more under ServerScriptService/Modules.
  • Shared catalogs — Config, SeedData, ShopCatalog, PetData, DecorCatalog in ReplicatedStorage.
  • Client — large LocalScript UI (HUD, shops, hotbar, estate, settings, audio, toasts).
  • Persistence — versioned DataStore schema with safe load (never overwrite cloud data after a failed load).

Shipping

Experience published on Roblox with store icon / thumbnails, Developer Products for coin packs, and a wipeable DataStore version for clean launches. Source and Studio install docs live on GitHub for portfolio review.

Stack & role

Solo build end-to-end: systems design, Luau server/client, economy balancing, UI, and publish. Stack: Roblox Luau, RemoteEvents, DataStores, MarketplaceService.
